# bronsonj98.github.io

Source for the personal academic website of Moonseong (Bronson) Jeong, https://bronsonj98.github.io/, built with Jekyll on GitHub Pages from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (MIT License; see LICENSE).

Content lives in `_pages/` (home, CV, publications, talks, teaching, news), `_publications/`, `_talks/`, `_teaching/`, `_data/news.yml`, and `llms.txt`. Layouts are `_layouts/site.html` (skeleton), `home.html`, `page.html`, and `entry.html` (publication, talk, and course pages); all styles are in `assets/css/site.css`. Figures for the publication rows are SVGs in `images/figures/`, generated by `images/figures/make_figures.py`. The PDF CV in `files/` is built from `cv_src/cv.tex` with Tectonic; `cv_src/` is excluded from the Jekyll build.

Pushing to `master` triggers the GitHub Pages build; check it with `gh run list -R bronsonj98/bronsonj98.github.io`.
